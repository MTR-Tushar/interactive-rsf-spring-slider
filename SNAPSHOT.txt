 STANDING CAVEAT
   Passing these checks shows the code solves the equations it claims to
   solve and that the controls behave as specified. It is NOT evidence that
   the model describes any real rock. This model is zero-dimensional and
   quasi-dynamic: no nucleation length, no rupture front, no spatial
   boundaries, no acoustic emissions. Radiation damping is not full inertia.
   Successful execution is not scientific validation.
